# Dokumente für den E-Mail-Versand

Hier liegen statische Dokumente, die das System an E-Mails anhängt.

## One Pager (Anhang der First-Call-Entscheidungs-Mail)

Die nach dem Erstgespräch versendete **Entscheidungs-Mail** hängt automatisch
eine PDF aus diesem Verzeichnis an.

- Es wird die Datei **`onepager.pdf`** bevorzugt (Groß-/Kleinschreibung egal,
  z. B. `Onepager.pdf` funktioniert ebenfalls); gibt es keine, wird die erste
  beliebige `.pdf` in diesem Ordner genommen.
- Ist gar keine PDF vorhanden, wird die Mail trotzdem versendet – dann **ohne
  Anhang** (im Aktivitätsprotokoll des Leads wird das vermerkt).

Lege hier also die aktuelle One-Pager-PDF der Copilot Partner Masterclass ab
und committe sie ins Repo.
